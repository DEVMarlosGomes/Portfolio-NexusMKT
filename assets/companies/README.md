# Company Images

Adicione as imagens das empresas aqui com o nome exato referenciado no HTML.

Nomes esperados:
- `company-placeholder-1.jpg`
- `company-placeholder-2.jpg`
- `company-placeholder-3.jpg`
- `company-placeholder-4.jpg`

Substitua os `[NOME_EMPRESA_X]` no `index.html` pelos nomes reais e renomeie as imagens correspondentemente.

Formato recomendado: JPG ou PNG, proporção quadrada ou 4:3, mínimo 480×480px.
